# Images and Character Art

This is the dedicated image library for **My Pet Rock Is Complicated**.

## Folders
- [source/](source/): original renders, references, and working GIMP files. Drafts only.
- [approved/](approved/): creator-corrected canonical master images.
- [exports/](exports/): resized/lettered/cropped derivatives for comics, video, website and print.
- [backgrounds/](backgrounds/): environment and location art.
- [props/](props/): props, interfaces, gadgets and R.O.C.K. design studies.

## Approval rules
A creator-edited master supersedes a generated draft. For **Optout**, every approved art file must have natural **horizontal goat pupils**. For **OptIn**, preserve the polished, smiling, red-haired villain aesthetic.

When art is uploaded, add an inventory entry with path, source, resolution, revision and approved/draft status.
